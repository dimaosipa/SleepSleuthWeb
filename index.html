SleepSleuth lives in your menu bar and shows you exactly which apps and processes are preventing your Mac from sleeping — in real time.

Download on the Mac App Store View on GitHub

Features

🔍

Real-Time Monitoring

Polls macOS power assertions every few seconds and listens for system changes, so you always have the latest picture.

📋

Detailed Assertion Info

See the process name, reason, assertion type, and how long each assertion has been active — all at a glance.

🔔

Notifications

Get a native macOS notification whenever a new sleep-preventing assertion appears, so nothing sneaks by.

📈

History & Statistics

Track which processes are the worst offenders with a 7-day rolling history, daily counts, and total blocked time.

⚡

Take Action

For user-owned processes, get a ready-to-use kill command and one-click Terminal access to reclaim your Mac’s sleep.

💫

Lightweight & Native

Built with SwiftUI. No Electron, no web views. Runs quietly in the menu bar with minimal resource usage.

How It Works

1

Install

Get SleepSleuth from the Mac App Store. It runs from your menu bar.

2

Monitor

The menu bar icon fills in when something is preventing sleep. Click to see the full list.

3

Act

Drill into any assertion to see details, or kill the offending process directly from the app.
